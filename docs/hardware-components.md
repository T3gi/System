# Аналіз апаратних компонентів системи вентиляції
## 1. Головна плата керування NUCLEO-F411RE
* **Мікроконтролер:** STM32F411RET6 (у корпусі LQFP64 на 64 ніжки).
* **Програматор:** На платі вже розпаяний вбудований програматор/дебагер ST-LINK/V2-1, який також працює як віртуальний COM-порт (потрібно для передачі тексту через UART).
* **Живлення:** Плата може живитись як від звичайного USB-кабелю (через роз'єм ST-LINK), так і від зовнішніх джерел живлення.
* **Роз'єми для підключення датчиків:** Плата має стандартні конектори Arduino Uno V3, а також розширені гребінки "ST morpho", які дають повний доступ до всіх виводів (ніжок) мікроконтролера.
* **Елементи керування на платі:** 1 користувацька кнопка, 1 кнопка Reset та 1 користувацький LED-індикатор.
## 2. Модуль камери OV7670
* **Напруга живлення:** Для цифрового ядра потрібна напруга 1.8V (±10%), для аналогової частини 2.45V - 3.0V, а для I/O (вводу/виводу) 1.7V - 3.0V. **Критично важливо:** логіка не толерантна до 5V!
* **Інтерфейс керування:** SCCB (повністю сумісний з шиною I2C). Максимальна частота 400 KHz.
* **Інтерфейс даних (DCMI):** 8-бітна паралельна шина даних (піни D0-D7), а також піни синхронізації VSYNC (кадр), HREF (рядок), PCLK (піксельний годинник) та XCLK (вхідний тактовий сигнал).

## 3. Сервопривід Tower Pro SG92R
* **Напруга живлення:** 4.8V (зазвичай живиться від окремого джерела 5V, а не напряму від мікроконтролера).
* **Інтерфейс керування:** ШІМ-сигнал (PWM).
* **Характеристики:** Швидкість реакції 0.1 сек / 60 градусів при живленні 4.8V.

## 4. IMU-сенсор MPU-6050 (Гіроскоп + Акселерометр)
* **Напруга живлення:** MPU-6050 підтримує живлення логіки через окремий пін VLOGIC (зазвичай 3.3V).
* **Інтерфейс керування:** I2C (підтримує швидкість до 400 kHz).
* **Адресація:** За замовчуванням пристрій має адресу `0x68` на шині I2C (визначається регістром WHO_AM_I). 

## 5. Флеш-пам'ять W25Qxx (SpiFlash)
* **Напруга живлення:** Залежно від маркування підтримує 3V (2.7-3.6V), 2.5V або 1.8V. Для плати Nucleo використовуємо версію на 3.3V.
* **Інтерфейс керування:** Стандартний SPI (також підтримує Dual-SPI, Quad-SPI та QPI).
* **Піни:** CLK (годинник), /CS (вибір мікросхеми, Chip Select) та піни вводу/виводу даних IO (MISO/MOSI).
* **Швидкість:** Підтримує тактову частоту шини SPI до 104 MHz або 133 MHz.

## 6. USB-UART конвертер YP-05 (чіп FT232RL)
* **Напруга живлення:** Вхідна напруга від 3.3V до 5.25V.
* **Логічні рівні:** Модуль має спеціальний джампер (перемикач), яким обов'язково треба обрати рівень логіки: 3.3V або 5V. Для Nucleo встановлюємо на 3.3V.
* **Піни:** DTR, RX, TX, VCC, CTS, GND.

## 7. Логічний аналізатор (8 каналів, 24 МГц)
* **Робоча напруга:** Працює з логічними рівнями 5V, 3.3V, 2.5V та 2.0V. Напруга логічної "1" розпізнається від 2.0V до 5.25V.
* **Характеристики:** Частота семплювання до 24 МГц на канал.
* **Призначення:** Підтримує апаратний аналіз протоколів UART, I2C, SPI. Використовуватиметься на етапі тестування (Крок 6) для зняття осцилограм сигналів.
