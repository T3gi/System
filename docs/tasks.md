# Задачі продукту: FR, період / подія, дедлайн

Перелік задач super-loop прошивки (ЛР3). Дедлайн — найпізніший момент, до якого задача має завершити реакцію, щоб вимога PRD вважалась виконаною. Числові дедлайни прийнято командою в ЛР3: у PRD є лише функціональні вимоги, тож ці числа треба також внести в PRD як нефункціональні вимоги. Ці ж задачі й дедлайни переносяться в ЛР4 (FreeRTOS) без змін.

| Задача | FR | Запуск | Дедлайн | Блокувальні виклики всередині |
| :--- | :--- | :--- | :--- | :--- |
| `temp_task` | FR-01, FR-02, FR-03 | період 1000 мс | наступне читання не пізніше ніж через 1000 мс + 10 мс; рішення про заслінку — у тому ж проході | `HAL_I2C_Mem_Read`, тайм-аут 100 мс |
| `camera_task` | FR-04, FR-05, FR-06 | 500 мс після попередньої зйомки (фактично раз на кадр ≈ 600 мс) | жест розпізнається не пізніше ніж через 2 кадри (≈ 1,2 с) після закриття об'єктива | очікування кадру (до ≈ 85 мс, тайм-аут 2 с) + 8 рядків з вимкненими перериваннями (≈ 16 мс) |
| `damper_changed` | FR-02, FR-05, FR-07 | подія від `temp_task` / `camera_task` | серво і запис у журнал — у тому ж проході | стирання сектора W25Q64: 45 мс типово, 400 мс макс. (datasheet); програмування сторінки 0,7–3 мс |
| `led_task` | FR-08 | кожен прохід | зміна стану LED не пізніше ніж через 50 мс після зміни стану заслінки | — |
| `Console_Poll` | командний інтерфейс | кожен прохід | відповідь на коротку команду ≤ 100 мс | команди `FRAME`, `SNAP`, `FERASE` — від сотень мс до десятків секунд |
| `button_task` | ручна зйомка кадру | фронт кнопки B1 | — (довга операція за запитом користувача) | передача кадру CIF по UART ≈ 31 с |
| `Process_Button_Event` | вимірювання реакції | прапорець з EXTI | ≤ 50 мс від натискання | блокувальний `printf` |
| `tick_task` | діагностика | період 1000 мс | ±10 мс | блокувальний `printf` ≈ 12 мс |
