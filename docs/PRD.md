# Product Requirements Document (PRD): Автоматизована система вентиляції

## 1. Концепція продукту
Система розумної вентиляції для приміщень, що автоматично керує повітряним потоком на основі температурних показників та візуальних команд (жестів). Головна мета — забезпечення енергоефективного клімат-контролю з можливістю безконтактного ручного перевизначення (override) стану системи.

## 2. Апаратні залежності
* **Контролер:** STM32 Nucleo-F411RE.
* **Сенсор 1:** Модуль GY-89 (I2C) для безперервного моніторингу клімату.
* **Сенсор 2:** Камера OV7670 (DCMI/I2C) для розпізнавання керуючого жесту.
* **Виконавчий механізм:** Сервопривід Tower Pro SG92R (PWM) для фізичного відкриття та закриття заслінки.
* **Сховище даних:** SPI-flash W25Qxx для логування подій (фіксація часу та причини спрацювання).

## 3. Функціональні вимоги
1. **Температурний тригер:** Система повинна безперервно зчитувати дані з GY-89. Якщо температура перевищує заданий поріг (наприклад, 26°C), мікроконтролер генерує ШІМ-сигнал для повороту сервопривода на 90 градусів (відкриття вентиляції).
2. **Візуальний тригер:** Камера OV7670 безперервно захоплює кадри. При виявленні заздалегідь визначеного патерну (наприклад, перекриття об'єктива рукою або розпізнавання руху в певній зоні) система змінює стан заслінки на протилежний, блокуючи температурний контроль на наступні 5 хвилин.
3. **Гістерезис клімат-контролю:** Для уникнення постійного "смикання" сервопривода, автоматичне закриття заслінки має відбуватися лише після того, як температура впаде на 2°C нижче порогу відкриття (до 24°C).
4. **Журналювання подій:** Кожна зміна стану вентиляції (відкрито/закрито) та джерело команди ("Спрацював датчик температури" або "Спрацювала камера") повинні записуватися у зовнішню пам'ять W25Qxx по шині SPI.
5. **Індикація стану:** Вбудований на платі LED-індикатор повинен світитися, коли заслінка відкрита, і блимати в момент запису логів у флеш-пам'ять.

## 4. План тестування (Критерії приймання)
* **Тест №1 (Стрес-тест температури):** Штучно нагріти датчик GY-89 (наприклад, подихом або теплим предметом). Очікуваний результат: сервопривід повертається, відкриваючи вентиляцію, у термінал UART виводиться повідомлення про подію.
* **Тест №2 (Оптичний override):** Привести систему в закритий стан за кімнатної температури. Зробити заданий жест перед камерою. Очікуваний результат: сервопривід негайно відкриває заслінку.
* **Тест №3 (Читання логів):** Перезавантажити мікроконтролер кнопкою Reset. Очікуваний результат: під час старту система вичитує з пам'яті W25Qxx останні збережені події та виводить їх історію у UART-термінал комп'ютера.
